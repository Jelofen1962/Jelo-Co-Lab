# Support

- **Bug reports:** open a GitHub issue with the release version, OS, VS Code version, Node.js version (for server issues), reproduction steps, and redacted logs.
- **Feature requests:** explain the workflow and user problem before proposing an implementation.
- **Security issues:** do not file a public issue with exploitable details. Follow `SECURITY.md` and use GitHub private vulnerability reporting if enabled for this repository.

Never attach workspace contents, authentication tokens, private keys, `.env` files, or customer data to public issues.

This is a community-maintained project. No paid support SLA or guaranteed response time is provided.
